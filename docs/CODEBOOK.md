# Compact release codebook

## `data/example/example_transitions.csv.gz`

- `GAGE_ID`: eight-character USGS station identifier.
- `date`: observation date.
- `q_cfs`: daily mean streamflow in cubic feet per second.
- `qualifier`: USGS value qualifier retained for measurement-sensitivity checks.
- `pr_mm`, `pet_mm`: basin-average daily precipitation and reference evapotranspiration in millimeters.
- `tmin_c`, `tmax_c`, `tmean_c`: basin-average daily temperature fields in degrees Celsius.
- `q_mm_day`: daily discharge normalized by basin area.
- `snowmelt_risk`: proxy indicator of possible snowmelt input.
- `q_norm`: discharge normalized by the basin-specific scale used in the analysis.
- `q_next_*d`, `dq_norm_*d`, `valid_transition_*d`: future normalized flow, increment, and validity at the stated lag.
- `dry_p0p1_a3_l*d`: no-detected-effective-input flag using the primary 0.1 mm precipitation threshold, three-day antecedent window, and stated lead.
- `select_*`: final contiguous-run selection flags written by Stage 10.

`make demo` writes `outputs/example/example_gage_selection.csv`, which records the regional candidate-pool size, robust medoid distance, and the six diagnostics used to select each example.

## `data/derived/basin_sample.csv.gz`

One row for each source GAGES-II gage. `accepted` marks the quality-controlled analysis sample and `estimable` marks availability of the one-day variance exponent.

## `data/derived/basin_scaling.csv.gz`

One row per accepted basin. Key fields include transition count, variance exponent `m`, water-year bootstrap limits, coefficient, fit `R²`, geographic coordinates, and descriptive ecoregion.

## `data/derived/basin_distribution.csv.gz`

One row per basin with an estimable exponent. It contains standardized-residual skewness, excess kurtosis, two-sided tail frequency, its Gaussian reference, and conservative-screen diagnostics.

## `data/derived/basin_signed_tails.csv.gz`

Primary-screen positive and negative three-standard-deviation frequencies and their multiples of the one-sided Gaussian reference.

## `data/derived/basin_theory_bridge.csv.gz`

Matched decline exponent, recession-rate exponent, classical `2b` prediction, direct `gamma`, sign-mixture shares, and water-year uncertainty indicators.

## `data/derived/basin_prediction_q10.csv.gz`

Basin-level Q10 prediction metrics for the global Gaussian, flow-state Gaussian, and flow-state empirical residual models. The verifier uses transition-count weighting, matching the paper analysis.

## `data/derived/basin_place_metrics.csv.gz`

One row per accepted basin, combining the HUC2 reporting stratum with `lambda_star`, signed-tail multiples, matched-theory `gamma`, the negative within-sign variance share, and the basin-level three-day Q10 empirical-shape CRPS gain. The table is assembled from frozen analysis outputs without using manuscript artwork or plotting code.

## `outputs/verification/huc02_summary.csv`

Generated by `make verify`. For each HUC2 reporting stratum and available place metric, it records the basin count, first quartile, median, and third quartile. These are descriptive summaries; HUC2 units are not treated as causal process domains.

## Compact population summaries

The uncompressed CSV files in `data/derived/` retain only the rows and fields needed for population-level checks:

- `scaling_population_summary.csv`, `scaling_meta_analysis.csv`, and `scaling_lag_stability.csv` contain the exponent distribution, random-effects synthesis, and cross-lag comparisons.
- `distribution_population_summary.csv`, `signed_tail_population_summary.csv`, and `robust_scale_population_summary.csv` contain the standardized-innovation and robust-scale sensitivity summaries.
- `theory_point_estimates.csv` and `theory_bootstrap_intervals.csv` contain the recession-theory contrasts and their water-year uncertainty intervals.
- `prediction_skill_summary.csv` and `prediction_water_year_summary.csv` contain the spatial-hierarchical and water-year-block prediction comparisons by low-flow threshold and lead.

## `data/expected/reported_claims.csv`

One row per registered paper claim, with a stable claim identifier, expected full-precision value, absolute comparison tolerance, displayed manuscript value, and plain-language description. It is a selected claim registry, not a transcription of every number in the article.
